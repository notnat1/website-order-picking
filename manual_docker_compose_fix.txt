# Manual Fix: Docker Compose File Update and Push

This guide provides the definitive steps to fix your local `docker-compose.yml` file and push the changes to GitHub. This is crucial for Jenkins to pick up the correct configuration.

---

### **Part 1: Manually Edit `docker-compose.yml` on Your LOCAL Machine**

**Objective:** Ensure your `docker-compose.yml` file is configured to expose the frontend on the correct, non-conflicting port (`8088`).

1.  **Open the file `D:\kevin\website-order-picking\docker-compose.yml`** in a text editor on your **local Windows machine** (e.g., VS Code, Notepad++).

2.  **Delete all the content** currently in that file.

3.  **Copy and paste the entire block of code below** into the file. This is the final, correct version with the frontend exposed on host port `8088`.

    ```yaml
    version: '3.8'

    services:
      backend:
        build:
          context: ./inventaris-backend
          dockerfile: Dockerfile
        container_name: inventaris_backend_app
        restart: always
        ports:
          - "5001:5001"
        environment:
          DATABASE_URL: mysql://${MYSQL_USER}:${MYSQL_PASSWORD}@db:3306/${MYSQL_DATABASE}
          JWT_SECRET: ${JWT_SECRET}
          PORT: 5001
        depends_on:
          - db
        networks:
          - inventory-net

      frontend:
        build:
          context: ./inventaris-frontend
          dockerfile: Dockerfile
        container_name: inventaris_frontend_app
        restart: always
        ports:
          - "8088:80" # Expose frontend to host port 8088
        environment:
          VITE_API_BASE_URL: /api
        depends_on:
          - backend
        networks:
          - inventory-net

      db:
        image: mysql:8.0
        container_name: inventaris_mysql_db
        restart: always
        environment:
          MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
          MYSQL_DATABASE: ${MYSQL_DATABASE}
          MYSQL_USER: ${MYSQL_USER}
          MYSQL_PASSWORD: ${MYSQL_PASSWORD}
        ports:
          - "3306:3306"
        volumes:
          - db_data:/var/lib/mysql
        networks:
          - inventory-net

    volumes:
      db_data: {}

    networks:
      inventory-net:
        driver: bridge
    ```

4.  **Save the file.**

---

### **Part 2: Push the Fix to GitHub**

**Objective:** Send the corrected `docker-compose.yml` to your GitHub repository, which will trigger Jenkins.

1. Open a terminal on your local Windows machine (ensure you are in the project directory: `D:\kevin\website-order-picking`).
2. Run the following Git commands to commit and push this change to GitHub:

    ```bash
    git add docker-compose.yml
    git commit -m "Final: Expose frontend on port 8088 in docker-compose.yml"
    git push origin main
    ```

3. **Monitor the Jenkins build output carefully.** It should now succeed completely, including the Docker Compose deployment and Prisma migrations.

---

**Important Note:** After this Jenkins build succeeds, you will still need to manually configure your Nginx server on your VPS to proxy to `http://localhost:8088`. The steps for that are in the `comprehensive_deployment_guide.txt` file (Part 2), which I provided earlier.
