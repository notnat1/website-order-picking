# Comprehensive Deployment Guide for inventory-app.natte.site

This guide consolidates all the necessary steps to get your application deployed and accessible at `https://inventory-app.natte.site/`, addressing all the issues we've encountered. Please follow these steps carefully and in order.

---

### **Part 1: Fix The Code on Your LOCAL Machine**

**Objective:** Ensure your `docker-compose.yml` file is configured to expose the frontend on a non-conflicting port (`8088`) and push this change to GitHub so Jenkins can pick it up.

**Step 1.1: Manually Edit `docker-compose.yml`**

1.  On your **local Windows machine**, open the file `D:\kevin\website-order-picking\docker-compose.yml` in a text editor (e.g., VS Code, Notepad++).
2.  **Delete all the content** currently in that file.
3.  **Copy and paste the entire block of code below** into the file. This is the final, correct version with the frontend exposed on port `8088`.

    ```yaml
    version: '3.8'

    services:
      backend:
        build:
          context: ./inventaris-backend
          dockerfile: Dockerfile
        container_name: inventaris_backend_app
        restart: always
        ports:
          - "5001:5001"
        environment:
          DATABASE_URL: mysql://${MYSQL_USER}:${MYSQL_PASSWORD}@db:3306/${MYSQL_DATABASE}
          JWT_SECRET: ${JWT_SECRET}
          PORT: 5001
        depends_on:
          - db
        networks:
          - inventory-net

      frontend:
        build:
          context: ./inventaris-frontend
          dockerfile: Dockerfile
        container_name: inventaris_frontend_app
        restart: always
        ports:
          - "8088:80" # Expose frontend to host port 8088
        environment:
          VITE_API_BASE_URL: /api
        depends_on:
          - backend
        networks:
          - inventory-net

      db:
        image: mysql:8.0
        container_name: inventaris_mysql_db
        restart: always
        environment:
          MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
          MYSQL_DATABASE: ${MYSQL_DATABASE}
          MYSQL_USER: ${MYSQL_USER}
          MYSQL_PASSWORD: ${MYSQL_PASSWORD}
        ports:
          - "3306:3306"
        volumes:
          - db_data:/var/lib/mysql
        networks:
          - inventory-net

    volumes:
      db_data: {}

    networks:
      inventory-net:
        driver: bridge
    ```

4.  **Save the file.**

**Step 1.2: Push the Fix to GitHub**

1.  Open a terminal on your local Windows machine (ensure you are in the project directory: `D:\kevin\website-order-picking`).
2.  Run the following Git commands to commit and push this change to GitHub:

    ```bash
    git add docker-compose.yml
    git commit -m "Final code fix: Expose frontend on host port 8088 in docker-compose.yml"
    git push origin main
    ```

3.  Wait for the Jenkins build to finish. **Monitor the Jenkins build output carefully.** It should now succeed completely, including the Docker Compose deployment and Prisma migrations.

### **Part 2: Configure the Nginx Server on Your LIVE VPS**

**Objective:** Correctly configure Nginx on your VPS to proxy requests from `https://inventory-app.natte.site/` to your Docker application running on port `8088`.

**Step 2.1: Connect to your VPS and become root**

1.  Connect to your server:
    ```bash
    ssh natte@62.84.186.196
    ```
2.  Become the root user:
    ```bash
    sudo -i
    ```
    Your prompt should change from `natte@vmi2909733:~$` to `root@vmi2909733:~#`.

**Step 2.2: Verify SSL Certificate Existence (for `inventory-app.natte.site`)**

Check if the SSL certificate for your domain exists.
```bash
ls -l /etc/letsencrypt/live/inventory-app.natte.site/
```
*   **If you see files** like `fullchain.pem` and `privkey.pem`, the certificate exists. Proceed to **Step 2.3**.
*   **If you get a "No such file or directory" error**, the certificate does not exist. You must generate it:
    ```bash
    certbot --nginx -d inventory-app.natte.site
    ```
    Follow Certbot's prompts. Choose the option to **redirect all HTTP to HTTPS**.

**Step 2.3: Update the Nginx Site Configuration for your Application**

1.  Open the site configuration file with nano:
    ```bash
    nano /etc/nginx/sites-available/inventory-app.natte.site
    ```
2.  **Delete all the content** in the file.
3.  **Copy and paste the entire Nginx configuration block below.** This version correctly points to **port 8088** for the frontend.

    ```nginx
    server {
        listen 80;
        server_name inventory-app.natte.site;

        # Redirect all HTTP traffic to HTTPS
        location / {
            return 301 https://$host$request_uri;
        }
    }

    server {
        listen 443 ssl http2;
        server_name inventory-app.natte.site;

        # SSL Certificate paths (ensure these match your Certbot paths if different)
        ssl_certificate /etc/letsencrypt/live/inventory-app.natte.site/fullchain.pem;
        ssl_certificate_key /etc/letsencrypt/live/inventory-app.natte.site/privkey.pem;
        include /etc/letsencrypt/options-ssl-nginx.conf;
        ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;

        # Main location for the frontend application
        location / {
            proxy_pass http://localhost:8088; # Correct port for frontend
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
        }

        # Location for the backend API calls
        location /api/ {
            proxy_pass http://localhost:5001/; # Backend port
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }
    }
    ```

4.  **Save the file and exit nano** (Press `Ctrl+X`, then `Y` to confirm save, then `Enter`).

**Step 2.4: Ensure Nginx is Using the Correct Configuration**

1.  **Remove any conflicting default Nginx site configuration.**
    ```bash
    rm /etc/nginx/sites-enabled/default
    ```
    (It's okay if this command gives a "No such file or directory" error; it means it's already gone.)

2.  **Disable any interfering Jenkins Nginx configuration.**
    ```bash
    rm /etc/nginx/sites-enabled/jenkins.natte.site
    ```
    (It's okay if this command gives a "No such file or directory" error; it means it's already gone.)

3.  **Ensure your `inventory-app.natte.site` config is enabled** (it likely is, but this ensures it). If it says "File exists", that's fine.
    ```bash
    ln -s /etc/nginx/sites-available/inventory-app.natte.site /etc/nginx/sites-enabled/
    ```

4.  **Test the Nginx configuration:**
    ```bash
    nginx -t
    ```
    (You should see `syntax is ok` and `test is successful`)

5.  **Restart Nginx to apply all changes:**
    ```bash
    systemctl restart nginx
    ```

**Step 2.5: Exit the root user shell**

```bash
exit
```

---

After completing all steps in **Part 1** and **Part 2**, clear your browser cache and cookies, then try accessing `https://inventory-app.natte.site/`. Your application should now be live.
