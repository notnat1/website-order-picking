================================================
PANDUAN RESET PASSWORD ADMIN DI VPS
================================================

Tujuan: Mereset password user 'admin' di database VPS Anda menjadi 'admin1234'.

------------------------------------------------
LANGKAH-LANGKAH
------------------------------------------------

# Ikuti langkah-langkah ini di dalam terminal VPS Anda:

**1. Masuk ke direktori backend:**
Pastikan Anda berada di direktori yang benar.
```bash
cd /var/www/inventory-app-src/inventaris-backend
```

**2. Buat file skrip baru menggunakan `nano`:**
Jalankan perintah ini untuk membuka editor teks `nano`.
```bash
nano resetAdminPassword.js
```

**3. Salin dan tempel kode berikut:**
Salin seluruh blok kode di bawah ini, lalu tempel ke dalam editor `nano` yang sudah terbuka.

```javascript
const { PrismaClient } = require('@prisma/client');
const bcrypt = require('bcrypt');

const prisma = new PrismaClient();

async function main() {
  const username = 'admin';
  const newPassword = 'admin1234';

  console.log(`Mencari user: ${username}...`);
  const user = await prisma.user.findUnique({
    where: { username },
  });

  if (!user) {
    console.error(`Error: User dengan username '${username}' tidak ditemukan.`);
    return;
  }

  console.log('User ditemukan. Membuat hash password baru...');
  const saltRounds = 10;
  const hashedPassword = await bcrypt.hash(newPassword, saltRounds);
  console.log('Hash berhasil dibuat.');

  const updatedUser = await prisma.user.update({
    where: { id: user.id },
    data: { password: hashedPassword },
  });

  console.log(`\nBERHASIL! Password untuk user '${updatedUser.username}' telah direset.`);
  console.log(`Anda sekarang bisa login dengan username '${username}' dan password '${newPassword}'.`);
  console.log('PENTING: Jangan lupa hapus file ini (resetAdminPassword.js) setelah selesai!');
}

main()
  .catch((e) => {
    console.error('Terjadi error:', e);
    process.exit(1);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

**4. Simpan dan keluar dari `nano`:**
- Tekan `Ctrl + X`
- Tekan `Y` untuk konfirmasi menyimpan
- Tekan `Enter` untuk keluar

**5. Jalankan skrip tersebut:**
```bash
node resetAdminPassword.js
```

Jika skrip berhasil, Anda akan melihat pesan "BERHASIL!". Sekarang coba login di website Anda dengan:
- **Username:** `admin`
- **Password:** `admin1234`

**6. (PENTING!) Hapus skrip setelah berhasil:**
Setelah Anda berhasil login, segera hapus file skrip tersebut demi keamanan.
```bash
rm resetAdminPassword.js
```

================================================
SELESAI
================================================

================================================
LANJUTAN: MEMPERBAIKI DATABASE KOSONG (P3005)
================================================

Jika Anda mendapatkan error "P3005: The database schema is not empty" saat menjalankan `npx prisma migrate deploy`, itu berarti database `api_dev` sudah ada isinya, tapi bukan yang diharapkan Prisma.

Solusi paling bersih adalah menghapus database tersebut dan membiarkan Prisma membuatnya ulang.

**Peringatan:** Ini akan menghapus semua data yang mungkin ada di dalam database `api_dev`.

Ikuti langkah-langkah ini di direktori `inventaris-backend`:

**1. Hapus dan buat ulang database `api_dev`:**
Jalankan perintah ini. Password `root_password_change_me` langsung dimasukkan di dalam perintah.
```bash
mysql -u root -p'root_password_change_me' -h 127.0.0.1 -P 4329 -e "DROP DATABASE IF EXISTS api_dev; CREATE DATABASE api_dev;"
```

**2. Jalankan lagi perintah migrasi Prisma:**
Setelah database bersih, jalankan perintah ini untuk membuat semua tabel.
```bash
npx prisma migrate deploy
```

Setelah langkah ini berhasil, database Anda akan memiliki semua tabel yang benar. Anda kemudian bisa kembali ke langkah **5. Jalankan skrip tersebut** di bagian atas panduan ini untuk mereset password admin.

================================================
FINAL: DEPLOYMENT DAN RESET ADMIN SETELAH SEMUA PERBAIKAN
================================================

Setelah semua file migrasi dan skrip `resetAdminPassword.js` diperbaiki di **komputer lokal** Anda, ikuti langkah-langkah ini:

**1. Push semua perbaikan ke GitHub (di komputer lokal Anda):**
```bash
git add .
git commit -m "Fix: Correct all migration file errors and update reset script"
git push origin main
```

**2. Jalankan perintah-perintah ini di VPS Anda (di direktori `inventaris-backend`):**
```bash
# 1. Tarik semua perbaikan dari GitHub
git pull origin main

# 2. Hapus dan buat ulang database untuk memastikan kebersihannya
mysql -u root -p'root_password_change_me' -h 127.0.0.1 -P 4329 -e "DROP DATABASE IF EXISTS api_dev; CREATE DATABASE api_dev;"

# 3. Jalankan migrasi yang sudah diperbaiki
npx prisma migrate deploy

# 4. Jalankan skrip untuk membuat user admin
node resetAdminPassword.js

# 5. (PENTING) Hapus skrip setelah selesai
rm resetAdminPassword.js

# 6. Restart server aplikasi Anda
#    (Hentikan proses lama, lalu mulai yang baru)
#    Cari PID-nya dulu:
ps aux | grep "node server.js" | grep -v grep
#    Lalu hentikan (ganti <PID> dengan nomornya):
sudo kill <PID>
#    Lalu jalankan lagi di background:
node server.js &
```

Setelah semua langkah ini selesai, website Anda seharusnya sudah berjalan, database sudah benar, dan Anda bisa login dengan `admin` / `admin1234`.
